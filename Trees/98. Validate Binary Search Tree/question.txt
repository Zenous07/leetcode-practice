98. Validate Binary Search Tree

Difficulty: Medium

Problem Statement:
Given the root of a binary tree, determine if it is a valid Binary Search Tree (BST).

A valid BST is defined as follows:

- The left subtree of a node contains only nodes with keys strictly less than the node's key.
- The right subtree of a node contains only nodes with keys strictly greater than the node's key.
- Both the left and right subtrees must also be binary search trees.

---

Example 1:
Input: root = [2,1,3]
Output: true

Explanation:
The left child (1) is less than the root (2), and the right child (3) is greater than the root (2).
Both subtrees satisfy the BST property, so the tree is a valid BST.

---

Example 2:
Input: root = [5,1,4,null,null,3,6]
Output: false

Explanation:
The root node's value is 5, but its right child has the value 4, which is less than 5.
This violates the Binary Search Tree property, so the tree is not a valid BST.

---

Constraints:
1 <= The number of nodes <= 10^4
-2^31 <= Node.val <= 2^31 - 1
