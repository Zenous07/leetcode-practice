700. Search in a Binary Search Tree

Difficulty: Easy

Problem Statement:
You are given the root of a binary search tree (BST) and an integer val.

Find the node in the BST whose value equals val and return the subtree rooted at that node. If such a node does not exist, return null.

---

Example 1:
Input: root = [4,2,7,1,3], val = 2
Output: [2,1,3]

Explanation:
The node with value 2 exists in the BST.
Return the subtree rooted at node 2, which is [2,1,3].

---

Example 2:
Input: root = [4,2,7,1,3], val = 5
Output: []

Explanation:
There is no node with value 5 in the BST.
Therefore, return null (represented as an empty array).

---

Constraints:
1 <= Number of nodes in the tree <= 5000
1 <= Node.val <= 10^7
root is a Binary Search Tree (BST).
1 <= val <= 10^7
